# 마스크폴 난이도 단계 설정 (2026-11-13)

앱(마스크폴)은 출격할 때마다 이 서버에 난이도 단계(1~10)를 묻고, 그 판에 쓴다. 단계별 배율은 앱 안(`quantumfighter-app/src/qf-tune.js`)에 있고, 서버는 숫자 하나만 고른다. 5단계 = 앱에 들어 있는 그대로.

## 관리 페이지

- 주소: https://www.donjiral.net/apps/maskfall/tune/ (메뉴·사이트맵에 없음, `noindex`)
- 암호: 백엔드 `ADMIN_SECRET`(업로드·예약 이름과 같은 암호, EC2 `~/pingpong.env`). 비어 있으면 아무도 못 연다.
- 같은 IP 에서 1시간에 10번 틀리면 그 시간 동안 잠긴다. 분당 120회 전체 제한은 따로.
- 고를 수 있는 것: 기본 단계(모든 앱), 버전별 단계(versionCode, 50개까지), 시험 코드와 단계.
- 보스 체력 %(2026-11-14, 30~200, 100 = 앱 그대로): 마지막 보스 체력에만 곱한다(단계의 적 체력 배율과 곱해짐). 시험 코드를 넣은 폰은 시험용 %를 따로 받는다. v135 이상 앱만 읽는다.
- 보스·난이도별 체력 %(일반·정예·악몽 × MF-01~MF-10 표, 각 30~200): 전체 % 위에 한 번 더 곱해진다. 시험 코드 폰에도 같은 값. 칸에는 보스 체력 숫자를 직접 넣고(기준 레벨·5단계에서의 값), 페이지가 앱 기본값 대비 %(소수 다섯째 자리)로 바꿔 보낸다. 칸마다 %와 격파 시간(정조준 기준)을 보여 준다 — 기준값은 페이지 안 `BOSS_HP`·`BOSS_P1`·`BOSS_MAX`(앱에서 보스 체력을 바꾸면 다시 재서 고친다).
- 시험 코드: 앱 첫 화면의 'PILOT' 글자를 3초 안에 5번 누르고 코드를 넣은 폰만 시험 단계를 받는다. 비우면 꺼진다.
- 저장할 때마다 기록이 남는다(최근 30개를 보여 줌).

## API (`backend/src/main/kotlin/net/donjiral/pingpong/maskfall/MaskfallTune.kt`)

| | |
|---|---|
| `GET /api/maskfall/tune?vc=<versionCode>&t=<시험 코드>` | 공개. `{"level":5,"source":"default"|"version"|"test","bossHp":100,"bossHpBy":[[일반 10개],[정예 10개],[악몽 10개]]}` — 시험 코드 → 버전 → 기본 순. `bossHp` 는 시험 코드면 시험용 %, 아니면 기본 % |
| `GET /api/maskfall/admin/tune` | `X-Admin-Secret` 필요. 설정 + 기록 |
| `PUT /api/maskfall/admin/tune` | `X-Admin-Secret` 필요. `{"defaultLevel":5,"versions":{"134":5},"testCode":"","testLevel":5,"bossHp":100,"testBossHp":100,"bossHpBy":[[…10개],[…],[…]]}` |

- 테이블: `maskfall_tune`(1행), `maskfall_tune_log`. JPA `ddl-auto: update` 가 만든다. 처음엔 행이 없어 기본 5.
- CORS: 앱(Capacitor) 출처 `https://localhost` 를 `application.yml` 에 넣었다.

## 앱 키 (2026-11-14)

- `GET /api/maskfall/tune` 은 EC2 `~/pingpong.env` 에 `export MASKFALL_APP_KEY='…'` 를 넣으면 `X-QF-Key` 헤더가 같은 요청만 답한다(아니면 403). 비워 두면 누구나 부를 수 있다.
- 값은 앱 저장소(비공개) `quantumfighter-app/src/qf-tune.js` 의 `TUNE_KEY` 와 같아야 한다. v135 이상 앱이 보낸다.
- 키는 앱 안에 들어 있어 앱을 뜯으면 나온다. 지나가는 호출을 막는 정도이고, 답에는 비밀이 없다(단계·보스 체력 %). 설정을 바꾸는 쪽은 계속 `ADMIN_SECRET`.
- 키를 바꾸려면 앱을 새로 배포하고, 예전 앱이 사라질 때까지는 서버에 넣지 않는다(예전 앱은 403 → 5단계로 출격).

## 배포

1. 이 저장소 `main` 에 푸시 → GitHub Pages 에 관리 페이지가 올라간다.
2. EC2 에서 `bash ~/redeploy.sh` → 백엔드가 새 API 와 함께 다시 뜬다(H2 데이터는 `~/pingpong-data` 그대로).
3. 확인: `curl https://api.donjiral.net/api/maskfall/tune?vc=134` → `{"level":5,"source":"default","bossHp":100,"bossHpBy":[[100,…],[…],[…]]}`.

서버가 꺼졌거나(1.5초 안에 답이 없음) 백엔드가 아직 옛 버전이어도(404·CORS 실패) 앱은 5단계로 출격한다. 예전에 받은 단계를 기억해 두지 않는다(사용자 2026-11-13).

## 로컬 시험

```bash
cd backend
JAVA_HOME=<JDK 17> gradle bootJar   # 또는 docker compose up --build
ADMIN_SECRET=local-test java -jar build/libs/pingpong-backend-0.0.1.jar --server.port=18080
```
관리 페이지는 `python3 -m http.server 8000` 으로 열고, 브라우저 콘솔에서 `localStorage.setItem('pingpong_api','http://127.0.0.1:18080')`.
