# 배포 가이드 — donjiral.net (앱 소개 사이트)

흐름: **소스를 GitHub에 푸시 → GitHub Pages가 바로 배포 → 카페24 도메인(www.donjiral.net) 연결**

---

## 1. GitHub에 푸시

저장소: https://github.com/sanghohan/donjiral.net (2026-11 `roulette` 에서 이름 변경 — 옛 주소는 GitHub이 새 주소로 넘겨줌)

```bash
git push origin main
```

- 예전 이름으로 받은 폴더라면 원격 주소를 한 번 바꿔 두세요: `git remote set-url origin https://github.com/sanghohan/donjiral.net.git`
- 비밀번호 대신 **Personal Access Token**이 필요해요: GitHub → Settings → Developer settings → Personal access tokens.

---

## 2. 호스팅 — GitHub Pages

저장소 Settings → Pages → Source `main` 브랜치(루트). 푸시하면 1~2분 뒤 반영되고 HTTPS는 자동입니다.
루트의 `CNAME` 파일(`www.donjiral.net`)이 커스텀 도메인을 지정합니다 — 지우지 마세요.

게시판·방문 수는 정적 사이트가 아니라 백엔드(`api.donjiral.net`)가 맡습니다 → `docs/탁구백엔드-배포가이드.md`.

---

## 3. 카페24 도메인(www.donjiral.net) 연결

카페24 **도메인 관리 → DNS 관리** 에서:

```
유형: CNAME
호스트: www
값: sanghohan.github.io
```

- 루트 도메인(`donjiral.net`, www 없는 주소)은 GitHub Pages용 **A 레코드**(`185.199.108.153` 등)로 연결돼 있고, GitHub이 `www.donjiral.net` 으로 넘겨줍니다.
- 백엔드는 `api`(게시판), `api-cham`(참교육) 호스트의 **A 레코드**가 EC2 IP를 가리킵니다. EC2를 옮기면 이 둘을 새 IP로 바꿔야 합니다.

DNS 반영에는 수 분~수 시간이 걸릴 수 있습니다.
